# Куб продаж

## Что обещано

MDX в работе не применялся — осваиваю его в учебном проекте на кубе SSAS (SQL Server Developer Edition) поверх витрины продаж. Шаги обещания:

1. Витрина продаж в форме «звезды» в MS SQL.
2. Многомерный куб SSAS с измерениями «дата», «товар», «клиент» и иерархиями в них.
3. 10–15 запросов MDX: срезы, накопление с начала года (YTD), сравнение с прошлым периодом (ParallelPeriod), ранжирование.
4. Подключение Excel к кубу.

## Итог одной фразой

Звезда продаж загружается в SQL Server 2022 и построчно совпадает с исходными данными; куб с тремя иерархиями описан в XMLA, создан и полностью обработан (ProcessFull, хранение MOLAP) в SSAS 2022 Multidimensional на временном раннере GitHub windows-2022; все 10 запросов MDX исполнены службой SSAS без правок текста, и ответы совпали с ожидаемыми, посчитанными двумя независимыми способами (pandas и SQLite); раньше те же запросы исполнены на заменяющем движке Mondrian 3.2; Excel к кубу не подключён.
